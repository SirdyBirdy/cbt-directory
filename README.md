# CBT Technique Finder

Quick-lookup index for *Cognitive Therapy Techniques* (Leahy, 2nd ed.). It lists technique names, chapters, book page numbers and the forms tied to each technique. It does not contain the book's text. Keep the book open alongside it.

Deploy: push these files to a repo, then Settings > Pages > Deploy from branch > `main` / root.

Files: `index.html` (the app), `data.js` (all entries; edit to add or retag), `sw.js` + `manifest.webmanifest` (offline and home-screen install).

Stars and notes are saved in the browser on each device. They do not sync between devices.

Keep the repo private or the content as is. Do not add the book's text or the forms to a public repo (the publisher's licence does not allow electronic display).
